# Cube Relic

**Cube Relic**은 복셀 아트(Voxel Art) 분위기의 HTML/JavaScript 기반 로그라이크 RPG 프로젝트입니다.

> **배포 상태:** 개발 중 · 첫 공개 배포 준비 중

## 게임 소개

다양한 직업과 스킬로 던전을 탐험하고, 층마다 다른 몬스터와 보스에 도전하는 게임입니다. 마을, 퀘스트, 아이템 등 다양한 시스템도 개발 중입니다.

## 다운로드

**아직 GitHub Releases에 공개된 게임 배포 파일이 없습니다.**

첫 공개 버전 배포 후 [Cube Relic Releases](https://github.com/JSeong2024/Cube-Relic/releases)에서 게임 파일과 패치노트를 확인할 수 있습니다.

## CR Launcher · 업데이트 확인

CR Launcher는 이 저장소의 [`version.json`](./version.json)을 확인해 최신 *공개* 버전을 안내하도록 설계할 예정입니다.

- `status: "unpublished"`: 공개 배포 전. 업데이트 다운로드를 안내하지 않습니다.
- `status: "published"`: `latest_version`과 로컬 버전을 비교합니다.
- 배포 파일은 GitHub Releases에 올리고, `download_url`은 실제 배포 파일의 URL로 설정합니다.
- `sha256`은 배포 파일 무결성 검사에 사용할 수 있습니다.
