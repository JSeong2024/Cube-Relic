# Cube Relic

**Cube Relic**은 복셀 아트(Voxel Art) 분위기의 HTML/JavaScript 기반 로그라이크 RPG 프로젝트입니다.

> **배포 상태:** 개발 중 · 첫 공개 테스트 릴리스 배포 완료  
> **최신 게임 버전:** `v0.6.7.3` · **CR Launcher 버전:** `v0.3.0.2` · **지원 플랫폼:** Windows

## 게임 소개

다양한 직업과 스킬을 활용해 던전을 탐험하고, 층마다 다른 몬스터와 보스에 도전하는 로그라이크 RPG입니다.

마을, 퀘스트, 아이템 등 다양한 시스템을 개발 중이며, 게임 콘텐츠와 배포·업데이트 기능을 지속적으로 개선하고 있습니다.

## 다운로드 및 설치

[**최신 Cube Relic 릴리스 확인하기**](https://github.com/JSeong2024/Cube-Relic/releases/latest)

| 다운로드 파일 | 용도 |
|---|---|
| [`CubeRelicSetup.exe`](https://github.com/JSeong2024/Cube-Relic/releases/download/v0.6.7.3/CubeRelicSetup.exe) | Windows용 Launcher 설치 프로그램 (**권장**) |
| [`Cube_Relic_v0.6.7.3.zip`](https://github.com/JSeong2024/Cube-Relic/releases/download/v0.6.7.3/Cube_Relic_v0.6.7.3.zip) | 수동 설치용 ZIP |

### 권장 설치 방법 — CR Launcher

1. `CubeRelicSetup.exe`를 다운로드하여 실행합니다.
2. 안내에 따라 CR Launcher를 설치합니다.
3. CR Launcher를 실행하고 게임 본편을 다운로드·설치합니다.
4. 설치가 완료되면 런처에서 게임을 실행합니다.

> 설치 프로그램은 **CR Launcher**를 설치합니다. 게임 본편은 런처에서 별도로 다운로드합니다.

### 수동 설치

1. `Cube_Relic_v0.6.7.3.zip`을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. 압축 해제된 게임 파일을 직접 실행합니다.

수동 설치 시 CR Launcher의 업데이트 및 백업 관리 기능은 자동으로 적용되지 않을 수 있습니다.

## CR Launcher · 게임 업데이트

CR Launcher는 이 저장소의 [`version.json`](./version.json)을 사용하여 최신 공개 게임 버전을 확인합니다.

- `status: "published"`: 공개 버전이 존재함을 나타냅니다.
- `latest_version`: 런처가 로컬 게임 버전과 비교할 공개 게임 버전입니다.
- `download_url`: GitHub Releases에 등록된 게임 ZIP의 다운로드 주소입니다.
- `sha256`: 배포 파일 무결성 검증에 사용하는 해시값입니다.
- 업데이트 과정에서 기존 게임 파일 백업 및 설치 실패 시 복구 기능을 지원합니다.
